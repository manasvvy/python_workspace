EXCEPTION HIERARCHY !!!!!!!

 EXCEPTION_HANDLING in python is achieved using try and except block
  
  1. try block ->try keyword
               ->the code which may rise exception  if occured should be written inside the try block 

  2. except block  ->keyword
                   ->the corroesponding handling code for exception needs to be written inside the except block 
  
  
working => 1. if code written in try block raises exception  only then the execution flow goes to the exception block for handling code 
           2. if there is no exception  in try block then it wont go to except block 

           APPROACH -> to get the exception information we can have the referance 

case2 : if a risky code is written above the try block then abnormal termination occurs 

case3 : when no specific exception name is handled then no termination error occur 

case4 : skippin below lines inside a try block if exception occurs in 1st line of try block then execution goes to except block without executing remaining lines

case5 : if exception occurs in the except block then abnormal termination occurs 

case6 : exception occuring below outside the except 
                                    

APPROACH2=> we can print exception info by creating the reference to the exception 

APPROACH3=> when there are multiple exceptions then we can write multiple except blocks for every exception type , a seprate exception block must be written

APPROACH4=> we can have each exception block inside a tuple aliasing it into referance variable but we cant write custom msg for each exception
