IMP FUNCTIONS ==>
                1. open() -> opens the file and establishes the connection between the file and py program 
                it returns the file object thru which we can perform operations
                syntax-> f=open("filepath","operation mode")

IMP ATTRIBUTES ==>
                1. f.name   -> name of file
                2. f.mode   -> mode of the file
                3. f.closed -> returns bool if file is closed    

DIFFERENT MODES==>
                1. 'r' -> read only
                = if file is present it opens it in read mode if file not fount then error    

                2. 'w' -> write
                = if file exists it opens the file in write mode but all the existing data will be erased
                = if the file is not there it creates new file of that name 

                3. 'a' -> append
                = it opens the file in write mode but it retains the existing data all write operations happen at the end only even if seek() is used
                = if file does not exist it creates the new file of that name and opens in write mode 

                4. 'r+' -> read and write
                = if file exists it opens in read and write mode 
                = if file does not exist file not found error

                5. 'w+' -> write and read 
                = if file exists it opens the file in write+read mode
                = if file is present it erases the existing content

                6. 'a+' -> append and read 
                = if file exists opens in append + read mode 
                = if file not found it creates a new file in write mode



FILE OBJECT METHODS ==>
                    1. readable() -> returns bool if the file is opened in the read mode
                    syntax: f.readable()

                    2. writeable()-> returns bool if the file is opened in the write mode
                    syntax: f.writeable() 

                    3. read(n) -> returns file as a string
                     n= characters of a string
                    syntax: data=f.read()

                    4. readline() -> if n is not given it reads complete line
                    syntax: data=f.readline()

                    7. readlines() -> reads all the lines and return them as list of stirng w each ele representing string
                    syntax: data=f.readline()

                    6. write(string) -> sends string data to python file it does not add a new line automatically u have to provide \n at the end of string 
                    syntax: f.write(string)

                    7. tell() -> returns the current file cursor position in the form or an int
                    syntax: position=f.tell()

                    8. seek(offset) -> moves the cursor to the position by passing int value
                    syntax: f.seek(offset)

                    9. close() -> closes the file and releases the resourcces associated w it , it dissconnects the program from the file
                    syntax: f.close()

                    10. writelines(list) -> writes element of iterable to the file it doesnt auto create a newline characters
                    syntax: f.writelines(list)
