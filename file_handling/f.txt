IMP FUNCTIONS ==>

                it returns the file object thru which we can perform operations
                syntax-> f=open("filepath","operation mode")

IMP ATTRIBUTES ==>
                1. f.name   -> name of file
                2. f.mode   -> mode of the file
                3. f.closed -> returns bool if file is closed    

DIFFERENT MODES==>
                1. 'r' -> read only
                = if file is present it opens it in read mode if file not fount then error    

                2. 'w' -> write
                = if file exists it opens the file in write mode but all the existing data will be erased
                = if the file is not there it creates new file of that name 

                3. 'a' -> append
                = it opens the file in write mode but it retains the existing data all write operations happen at the end only even if seek() is used
                = if file does not exist it creates the new file of that name and opens in write mode 

                4. 'r+' -> read and write
                = if file exists it opens in read and write mode 
                = if file does not exist file not found error

                5. 'w+' -> write and read 
                = if file exists it opens the file in write+read mode
                = if file is present it erases the existing content

                6. 'a+' -> append and read 
                = if file exists opens in append + read mode 
                = if file not found it creates a new file in write mode

                7. 'x' -> exclusive
                = if the file exists u get fileexisterror 
                = creates a new file in the write mode only if the file is not existing
                = used when u dont wanna overwrite an existing file


FILE OBJECT METHODS ==>
                    1. readable() -> returns bool if the file is opened in the read mode
                    syntax: f.readable()

                    2. writeable()-> returns bool if the file is opened in the write mode
                    syntax: f.writeable() 

                    3. read(n) -> returns file as a string
                    n= characters of a string
                    syntax: data=f.read()

                    4. readlines() -> reads all the lines and return them as list of stirng w each ele representing string
                    syntax: data=f.readline()

                    5. write(string) -> sends string data to python file it does not add a new line automatically u have to provide \n at the end of string 
                    syntax: f.write(string)

                    6. tell() -> returns the current file cursor position in the form or an int
                    syntax: position=f.tell()

                    7. seek(offset) -> moves the cursor to the position by passing int value
                    syntax: f.seek(offset)

                    8. close() -> closes the file and releases the resourcces associated w it , it dissconnects the program from the file
                    syntax: f.close()

                    9. writelines(list) -> writes element of iterable to the file it doesnt auto create a newline characters
                    syntax: f.writelines(list)

dumps() is a function of json module that converts python obj into json formatted string.

2. dump() -> syntax: json.dump(obj,f)

dump() is a function of json module that converts python obj into json format and writes it into file.

USING PICKLE MODULE
import pickle

PICKLING / SERIALISATION

 - Pickling converts a Python object into
 - a byte stream (binary data) and stores it
 - in a binary file.


 1) dumps() -> Syntax: byte_data = pickle.dumps(obj)

 dumps() is a function of the pickle module
 that converts a Python object into a byte stream.


 2) dump() -> Syntax: byte_data = pickle.dump(obj, f)

 dump() is a function of the pickle module
 that converts a Python object into a byte stream
 and writes it into a binary file.


 UNPICKLING / DESERIALISATION

 Unpickling is the process of converting
 a byte stream (binary data) back into
 the original Python object.

1) loads() -> Syntax: obj = pickle.loads(byte_data)

 loads() converts a byte stream back
 into the original Python object.


2) load() -> Syntax:obj = pickle.load(f)

 load() reads the byte stream from a binary file
 and converts it back into the original Python object.


#COMPLETE EXAMPLE
import pickle

python_obj = [10, 20, 30]

#Pickling using dumps()
byte_data = pickle.dumps(python_obj)

print(byte_data)

#Unpickling using loads()
object = pickle.loads(byte_data)

print(object)
print(type(object))


#FILE EXAMPLE
import pickle

python_obj = [10, 20, 30]

#Write object to binary file
with open("file_handling/demo.pkl", "wb") as f:
    pickle.dump(python_obj, f)


#Read object from binary file
with open("file_handling/demo.pkl", "rb") as f:
    object = pickle.load(f)

print(object)
print(type(object))
