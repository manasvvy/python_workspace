2 imp concepts :
 1. class

 syntax =

-----------MEMORY ALLOCATION------------

 -> when py encounters a class keyword it creates class dict and inside it all the class var and methods in the class wil be stored in the form of key val pair

 -> when an instance is created py will have a seperate instance dict which will store that instances data/states (instance variable)

VARIABLES WITH RESPECT TO CLASS AND INSTANCE

1. CLASS VARIABLES

 -> these are var that are defined instide the class but outside all methods

 -> variable that are created using the class name but outside the class

 -> only 1 copy of class variables is present for the entire class and its not tied to any instance

 -> class variable are stored in the class dict

 -> when any value is common for all the instances then such variables can be made class variable   
 
 syntax=
 class ClassName:
    variablename = value
 ClassName.variablename = value    

 syntax to modify the class variable=
  ClassName.variablename = new value


2. INSTANCE VARIABLES
 
 -> instance creation is mandatory to declare instance variable

 -> one copy of the instance , created seprately  for each instance

 -> if a var is unique we make it as instance varuable

WE CAN ACCESS OR MODIFY AN INSTANCE VARIABLES
   ACCESSING => instanceref.variablename
   MODIFYING => instanceref.variablename = new value

 -> modifying an instance variablewill only affect that specific instance   

syntax=
 instance_reference.variable_name = value

 ***METHODS WRT CLASS AND OBJECT***

ALL METHODS ARE STORED IN THE CLASS DICTIONARY

 1. CLASS METHODS

 -> belongs to class itself
 -> works on class level data and not on instance
 -> it recieves the class reference as the 1st parameter refered to class
 -> declared using @classmethod decorator just above the method

 SYNTAX(class method)- 
   class ClassName:
      @classmethod
      def methodname(cls,para1,2.......):
         #method body
      ClassName.methodname(arg1,a2,a3) 

 -> a class method can modified and access the class var
 -> accessing class method using ClassName.classmethod()
 -> when the operation is related to a class and not a particular instance we use class method 
 -> if there are n parameters in the class we should pass "n-1" arguments during the class method calling

 2. INSTANCE METHODS
 -> belongs to the instance
 -> works on a specific data
 -> it recieves current instance referance as the 1st parameter refered to self
 
 SYNTAX-
    class ClassName:
      def methodname(cls,para1,2.......):
         #method body
         #u can access or modify the instance variable
      referance=ClassName()

 3. STATIC METHODS
 -> not depend onn class or instance
 -> cant operate on class or instance methods
 -> it does not recieve self or cls as 1st parameters
 -> should be defined usind @staticmethod

      @staticmethod
      def method_name(p1,p2......)

-------------- INHERITANCE -----------------

   -> THE PROCESS OF 1 CLASS AQUIRING THE PROPERTIES PF ANOTHER CLASS
   -> THE CLASS WHICH SHARES THE PROPERTIES = PARENT CLASS
   -> THE CLASS WHICH AQUIRES THE PROPERTIES = CHILD OR SUB CLASS OR DERIVED CLASS
   -> INHERITANCE CAN BE REFERED TO AS 'IS-A-RELATIONSHIP'
   -> IN PY WE CAN INHERIT VARIABLES AND METHODS

 TYPES OF INHERITANCE ->
 
  1.SINGLE LEVEL      -> COMBINATION OF ONE PARENT CLASS AND ONE CHILD CLASS

  2.MULTI LEVEL       -> COMBINATION OF 2 OR MORE SINGLELEVEL INHERITANCES IN A SINGLE MANNER 

  3.HIERARCHIAL LEVEL -> 1SUPERCLASS HAVING 2 OR MORE SUBCLASSES

  4.MULTIPLE LEVEL    -> 1 SUBCLASS HAVING 2 OR MORE SUPERCLASSES
                         THE ATTRIBUTE AND BEHAVIOUR OF MULTIPLELEVEL SUBCLASSES CAN BE ACCESSED BY THE SUBCLASS

  5.HYBRID LEVEL      -> COMBINATION OF DIFF INHERITANCE TYPES


NOTE-> IF BOTH THE SUPERCLASS HAVE SAME ATTRIBUTE NAME OR METHOD 
BASED UPON THE MRO THE METHOD PRESENT IN THE IMMEDIATE SUPERCLASS WILL BE EXECUTED


SYNTAX=> 
SINGLE
class ParentClassName:
   #class body
   #parent PROPERTIES

class ChildClassName(ParentClassName):
   #CHILD CLASS BODY
   #child PROPERTIES

MULTI-
class A:
   #class body
   #parent PROPERTIES

class B(A):
   #CHILD CLASS BODY
   #child PROPERTIES

class C(B):
   #class body of C
   #child PROPERTIES
